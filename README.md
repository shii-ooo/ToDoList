## リマインダー
JavaScriptで作成したシンプルなリマインダーです

## 概要
タスクの追加・完了・削除ができるToDoリストを作成しました。
JavaScriptの基本的なDOM操作やイベント処理、localStorageを使ったデータ保存について学習することを目的として制作しました。

## 機能
・タスクの追加
・タスクの完了・未完了の切り替え
・タスクの削除
・「すべて」「未完了」「完了」の絞り込み
・未完了タスク数の表示
・localStorageを利用したタスクの保存

## 使用技術
・HTML
・JavaScript
・localStorage

## こだわったこと
### HTMLを直接書き換えず、JavaScriptで画面を更新
タスクを追加・削除・完了した際に、HTMLをその都度直接書き換えるのではなく、
JacaScriptでDOMを操作して画面を更新する方法で実装しました。

タスクの情報を配列でまとめて管理し、データを変更したあとに、そのデータをもとに画面を更新するようにしています。

この方法にすることで、タスクの追加・削除・完了だけでなく、今後新しい機能を追加するときも、
タスクのデータを変更して画面を更新するという同じ流れで処理できるようにしました。
